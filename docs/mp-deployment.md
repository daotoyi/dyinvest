
1. 构建微信小程序生产包。
2. 校验构建产物 AppID 必须为 `wx6aef5e7ef168ecdd`。
3. 调用微信开发者工具上传开发版。

## 公开发布步骤

以下操作需要小程序管理员或具备对应权限的运营人员，在微信公众平台完成：

1. 登录微信公众平台并进入该小程序的“管理 -> 版本管理”。
2. 将已上传的 `0.2.1` 设为体验版，添加体验成员并完成验收。
3. 在“设置 -> 基本设置”确认名称、头像、简介和服务类目。
4. 在“设置 -> 服务内容声明”和“用户隐私保护指引”中完成声明。
5. 准备主体资质、金融相关类目材料、风险提示和用户协议。
6. 从版本管理提交审核，审核通过后再执行“发布”。

## 发布前注意事项

- 当前内容为期权教育、策略分析和本地模拟，不连接券商或真实资金。
- 小程序金融类目和证券相关功能仍需按微信最新审核规则核对资质。
- 若审核要求提供证券投资咨询、经营许可或其他材料，应先完成合规确认。
- 审核期间保持服务器域名、隐私声明和实际功能一致。
- 发布前应使用体验版在 iOS 和 Android 真机各完成一次关键流程验收。

## 回滚

微信公众平台会保留历史版本。出现严重问题时：

1. 暂停或回退体验版。
2. 在版本管理中重新提交上一个稳定版本。
3. 修复后使用新版本号重新上传，避免覆盖问题版本。

## 版本记录

### 0.2.1

- 增加微信小程序手机号快捷登录按钮。
- 增加 `phoneLogin` 云函数，使用微信 OpenAPI 换取已验证手机号。
- 手机号账户支持创建、恢复和脱敏展示。
- H5 点击手机号登录会显示平台限制说明。
- 云函数部署前需要配置云开发环境 ID 和微信隐私授权。

### 0.2.0

- 增加本地用户注册、登录、退出和配置文件。
- 支持保存昵称、经验水平、风险偏好、默认策略和默认下单数量。
- 密码使用随机盐和 PBKDF2 哈希保存，不落明文。
- 当前账户和配置仅保存在本机，尚未接入云端认证与同步。

### 0.1.1

- 在 `app.json` 启用 `lazyCodeLoading: requiredComponents`。
- 修复微信预览时的“启用组件按需注入”质量检查问题。
- 重新上传开发版并生成真机预览二维码。
