# 运营管理后台

## 当前定位

当前管理台是随应用一起发布的本地管理端，用于验证后台信息架构和运营流程，不是生产环境的管理系统。

- 首个注册或首次手机号登录的本地账户自动成为管理员。
- 后续账户默认为普通用户，管理员可在后台调整角色和状态。
- 管理台只能修改当前设备上的本地数据。
- 没有服务端 RBAC、操作日志数据库和跨设备同步。

## 功能范围

### 数据概览

- 可用用户数和用户总数。
- 管理员数量。
- 已发布课程与已启用策略数量。
- 最近用户。
- 运营公告状态。
- 当前 AppID、应用版本和服务端 RBAC 状态。

### 用户管理

- 搜索昵称、用户名、手机号或风险等级。
- 设置或移除管理员角色。
- 禁用或恢复用户登录。
- 禁止管理员取消自己的管理员权限。
- 禁止管理员禁用当前登录账户。

### 内容发布

- 课程上下架，下架后从学习首页和课程目录隐藏。
- 策略启用或停用，停用后从策略实验室和用户默认策略选项中移除。
- 至少保留一节课程和一个策略。
- 一键恢复默认发布状态。

### 运营公告

- 启用或关闭首页公告。
- 编辑公告标题和正文。
- 预览首页展示效果。
- 保存后立即作用到当前设备的首页。

## 权限入口

管理员登录后，个人中心会出现“运营管理后台”入口。

页面路径：

```text
/pages/admin/index
```

无管理员权限时，页面显示权限拒绝状态，不展示管理数据。

## 生产化要求

正式上线前，需要把本地实现替换为服务端能力：

1. 服务端登录会话和 RBAC。
2. 课程、策略、公告和用户数据的数据库持久化。
3. 管理员邀请和管理员初始化流程。
4. 高风险操作二次确认和双人复核。
5. 操作审计日志、登录日志和风险告警。
6. 数据导出、删除和合规留存策略。
7. 管理后台独立域名、IP 白名单、MFA 和最小权限。

本地模式不能作为生产权限边界，也不能用于真实用户数据管理。
